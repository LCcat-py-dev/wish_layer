# 网站分类与方案速查

出 `classification` 和 `plan` 时才读。判域、可达集、槽位、复杂度在 `pack.md`。

## 1 分类与路线

| 编号 | 大类 | 核心闭环 | 可达性 |
|---|---|---|---|
| C-01 | 信息内容型 | 生产 → 组织 → 检索 → 阅读 | 全部可达 |
| C-02 | 交易商务型 | 浏览 → 下单 → 支付 → 履约 → 售后 | 仅裁剪版 |
| C-03 | 社交社区型 | 注册 → 发布 → 互动 → 分发 → 治理 | 仅小型 |
| C-04 | 工具应用型 | 注册 → 使用 → 协作 → 付费 → 续费 | 不可达 |
| C-05 | 服务办事型 | 查询 → 申请 → 提交 → 审批 → 结果 | 不可达 |

| 编号 | 路线 | 适合 | 代价 |
|---|---|---|---|
| R-1 | SaaS 建站（Wix、Framer、有赞） | 官网、落地页、轻电商 | 月费、定制差、数据受制于平台 |
| R-2 | 开源程序（WordPress、Ghost、Discourse） | 博客、媒体、论坛、中小电商 | 需维护服务器与插件安全 |
| R-3 | 静态站 + Git + CDN（Astro、Hugo、Vercel） | 官网、文档、博客、作品集 | 动态能力需外接 |
| R-4 | 全自研 | SaaS、平台、内部系统 | 最贵最慢，要团队 |

选路线的经验规则（`plan[]` 用得上）：无技术团队且做展示或轻电商 → `R-1`；长期做内容重 SEO → 有开发资源走 `R-3`，没有走 `R-2`；核心是交易、账户或复杂状态 → `R-4` 或成熟垂直 SaaS；首版产品一律先 MVP。

## 2 方案速查

| 编号 | 类型 | 推荐路线 | 周期量级 | 可达性 |
|---|---|---|---|---|
| M-01 | 企业官网、品牌站 | R-3 或 R-1 | 1–3 周 | 可达 |
| M-02 | 个人博客、作品集 | R-3 或 R-2 | 2–7 天 | 可达 |
| M-03 | 文档站 | R-3 | 3–10 天 | 可达 |
| M-04 | 资讯媒体、门户 | R-2 或 R-4 | 1–3 月 | 不可达 |
| M-05 | 电商独立站 | R-1 起步 | 2 周–3 月 | 不可达（单页裁剪版除外） |
| M-06 | 社区、论坛 | R-2 | 1–4 周 | 可达（小型） |
| M-07 | SaaS、Web 工具 | R-4 | 2–6 月 | 不可达 |
| M-08 | 在线教育 | R-4 + 云服务 | 1–3 月 | 不可达 |
| M-09 | 政务、企业内系统 | 低代码或 R-4 | 1–6 月 | 不可达 |
| M-10 | 活动落地页、H5 | R-1 或 R-3 | 1–3 天 | 可达 |
| M-11 | 小程序、移动端 | 独立技术栈 | 1–4 周 | 不可达 |
